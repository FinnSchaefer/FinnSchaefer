PULSER at IEEE HOST 2026

PULSER was accepted to IEEE HOST 2026. The work focuses on a simple problem: what happens when a system keeps trusting sensor data that has been manipulated, but still looks valid.

The target here is LiDAR. Not breaking it outright, but shifting it just enough that the system continues to accept it. The result is a change in how the system perceives its environment without triggering obvious faults.

What matters is not the specific sensor. It is the trust model. These systems assume that if the data looks consistent, it is safe to use. That assumption holds until it does not.

PULSER stays in that gap. The manipulation is subtle. The data remains believable. But the downstream effect is that the system builds the wrong understanding of the world and acts on it.

This is not a failure mode that shows up as a crash or a clear error. It propagates. Decisions are made on top of bad state, and the system has no reason to question it.

That is the point of the work. Not just that the input can be manipulated, but that it can be manipulated in a way that survives validation and moves through the rest of the stack.
