About

I work on security problems where trusted data shapes real systems.

I focus on cyber-physical systems, autonomous platforms, and the security problems that show up when software, sensors, telemetry, and control logic all depend on each other.

Most of the work here follows the same thread: understanding how trusted inputs can be manipulated, why that matters operationally, and how those failures carry into real environments.
